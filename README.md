# Express EJS Template Project 🚀

## 📌 Description
This is a simple Express.js project using EJS templates.  
It takes user input and displays a greeting message.

---

## 🛠️ Technologies Used
- Node.js
- Express.js
- EJS
- HTML & CSS

---

## 📂 Project Structure
- app.js → main server file  
- views/ → EJS templates  
- package.json → project dependencies  

---

## ▶️ How to Run

1. Install dependencies:
   npm install

2. Start server:
   node app.js

3. Open browser:
   http://localhost:3000

---

## 💡 Features
- Simple form input
- Dynamic greeting message
- Clean UI
